01

Connect Google on the server

Approve read-only access once. The server stores the refresh credential encrypted; no Google secret is sent to the tablet.

Disconnect removes Google tokens and Google cached events; iCalendar subscriptions are unchanged. It does not delete Google events or revoke another deployment's consent.

02

People and shared layout

Existing private v0.3 settings can be imported. Calendar names, IDs and settings are stored in the private server database, not the repository. This layout export does not include additional sources or subscription URLs; back up the database and encryption key for those.

People & display groups

Up to six people or display groups, such as Family. A person is a name and colour on the display, not a login account. Attach several sources to the same person; a work feed does not need another person.

Primary Google mapping is optional. Additional iCalendar or Google sources can be attached below.

Use [PW:WORK], [PW:ONCALL] or [PW:OFF] in editable calendars, or attach a rota-only subscription below with matching rules. Save the rota-band selection before adding its source. OFF must be all-day; on-call always implies working. Missing rota information remains unknown.

Layout, privacy and button behaviour

Working/on-call status is intentionally visible even when the shift title is private. The 19-second delay is an interaction experiment, not a pigment-waveform simulation.

03

Additional calendar sources

A person can have Google appointments and an iCalendar rota, school or club feed together. These are live, read-only subscriptions: nothing is copied into Google. Up to 24 additional sources.

New source

Internet-reachable HTTPS feeds, including private token links; do not make a private calendar public. The link itself may grant access: it is encrypted on the server, never returned to displays or exports. Local-network URLs, login pages and password-based feeds are not supported. webcal is upgraded to HTTPS.

Rota interpretation

Existing [PW:…] tags take priority. Otherwise, rules run top to bottom: first match wins, ignoring case. Use Equals for short shift codes. Contains can also match negative phrases such as “not on call”; put specific exceptions first.

Applies only after a successful, fresh sync. Unrecognised entries remain unknown.

Empty dates remain unknown unless the complete-rota option is enabled. On-call implies working. OFF must be all-day; a timed leave entry is not a whole day off. Source entries assigned to Rota never occupy appointment slots.

Start disabled, save, preview real entries below, then enable after checking dates and rules. Save any shared-layout changes before saving a source.

Private source preview

Save a source first. Preview uses saved rules, even while the source is disabled.

04

Pair your tablet

Create a one-time code here, then enter it on the tablet's display page. Codes expire in ten minutes. Device sessions can be revoked independently.

Synchronisation health

Each source is saved only after its full bounded fetch and validation have completed. Errors keep the last successful data. Browsing an uncached period queues it automatically.
