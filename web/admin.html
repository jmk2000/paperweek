Connect Google on the server

Approve read-only access once. The server stores the refresh credential encrypted; no Google secret is sent to the tablet.

Disconnect removes server tokens and cached events. It does not delete Google events or revoke another deployment's consent.

02

Choose calendars and the shared layout

Existing private v0.3 settings can be imported. Calendar names, IDs and settings are stored in the private server database, not the repository.

People & calendar mapping

Connect Google, then load calendar choices.

Use [PW:WORK], [PW:ONCALL] or [PW:OFF] at the beginning of event titles on this calendar. OFF must be all-day; on-call always implies working. Missing rota information remains unknown.

Layout, privacy and button behaviour

Working/on-call status is intentionally visible even when the shift title is private. The 19-second delay is an interaction experiment, not a pigment-waveform simulation.

03

Pair your tablet

Create a one-time code here, then enter it on the tablet's display page. Codes expire in ten minutes. Device sessions can be revoked independently.

Synchronisation health

Each calendar/month is saved only after every Google result page has loaded. Errors keep the last successful data. Browsing an uncached period queues it automatically.
