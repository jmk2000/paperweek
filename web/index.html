Accessible agenda & display notes

The display uses a 1600 × 1200 logical canvas. Screen colours and physical size are not calibrated to an e-paper panel.

MAKE IT YOURS

Calendar settings

Names and calendar IDs stay in this browser's settings. Nothing here is written to the source project. Tokens and event data are kept in memory only.

People & calendars

One to six calendars. Use distinct badges so colour is never the only identifier.

On the selected calendar, titles starting with [PW:WORK], [PW:ONCALL] or [PW:OFF] become a visual status band. OFF must be all-day; ONCALL implies working. Missing information is never treated as a day off.

Layout & controls

Set refresh to 19 to try the interaction delay. This uses a non-flashing placeholder, not a simulation of the real pigment waveform. Showing and hiding button help each require a refresh.

Google Calendar

Use a Web application client, not the desktop client from an earlier prototype. Enable Calendar API and register this site's exact origin. No API key, client secret or refresh token belongs in this page.

Browser access expires. Renew it with a button press; the prototype never silently pretends to stay synced. A reload needs a fresh connection. Shared calendars must be accessible to the one account used to sign in.

Local data

An exported settings file contains names and calendar IDs. Do not publish it. Screen exports also contain whatever is visible.
